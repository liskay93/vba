# ChartFormatter — 엑셀 차트 서식 자동화 VBA

차트는 직접 만들고, **차트를 클릭해서 선택한 뒤 매크로를 실행**하면 색상·폰트·크기·축·눈금선·범례 서식이 한 번에 적용됩니다.
**차트 위치(Left/Top)는 절대 바뀌지 않습니다.**

## 설치

1. 통합 문서를 **매크로 사용 통합 문서(.xlsm)** 로 저장합니다.
2. `Alt` + `F11` 로 VBA 편집기를 엽니다.
3. 메뉴 **파일 → 파일 가져오기**(`Ctrl` + `M`) → `src/ChartFormatter.bas` 선택.
4. `Alt` + `Q` 로 편집기를 닫습니다.

## 사용법

| 하려는 일 | 실행할 매크로 |
|---|---|
| 선택한 차트 1개 서식 적용 | `FormatSelectedChart` |
| 현재 시트의 모든 차트 서식 적용 | `FormatAllChartsOnSheet` |

차트를 한 번 클릭해서 선택한 다음 `Alt` + `F8` → `FormatSelectedChart` → 실행.

**단축키 등록을 권장합니다.** `Alt` + `F8` → 매크로 선택 → **옵션** → 바로 가기 키에 예를 들어 `Shift` + `F` 입력.
그러면 차트 클릭 후 `Ctrl` + `Shift` + `F` 만 누르면 됩니다.

> 시트에 **버튼 도형을 만들어 연결하는 방식은 쓰지 마세요.** 버튼을 클릭하는 순간 차트 선택이 풀려서
> "차트를 먼저 선택하세요" 메시지가 뜹니다. 단축키나 `Alt` + `F8` 로 실행해야 합니다.
> (`FormatAllChartsOnSheet` 는 선택이 필요 없으므로 버튼으로 써도 됩니다.)

## 적용되는 서식

- **계열 색상** — 아래 팔레트를 1번 슬롯부터 순서대로 배정. 원형 차트는 계열이 아니라 조각별로 배정.
- **크기** — 480 × 300 pt (위치는 그대로 유지)
- **폰트** — 맑은 고딕, 본문 10pt / 제목 14pt 굵게, 제목은 그래프 왼쪽 끝에 맞춰 정렬
- **축** — 눈금 표시 제거, 가로 눈금선만 연한 회색으로 남기고 세로 눈금선 제거, 값 축 선 제거·항목 축 선만 유지
- **범례** — 계열이 2개 이상이면 아래쪽에 자동 표시, 1개면 제거 (제목이 이미 이름을 말해주므로)
- **막대** — 간격 너비 80, 계열 사이에 미세한 틈, 채우기 경계는 배경색 1.5pt 선으로 분리
- **선** — 두께 2pt, 곡선 보정 해제, 마커가 있으면 6pt + 흰색 테두리
- **원형** — 조각별 색상 + 데이터 레이블(항목명 + 백분율), 범례 대신 레이블 사용
- **제거** — 그림자, 네온, 차트 테두리, 둥근 모서리, 그림 영역 배경

혼합 차트(막대+선)도 계열별 종류를 각각 판별해서 알맞게 처리합니다.

## 팔레트

색상은 임의로 고른 것이 아니라 **흰 배경 기준으로 색약 구분 거리를 실제 계산해서 통과한** 순서입니다.

| 슬롯 | 색 | HEX | 슬롯 | 색 | HEX |
|---|---|---|---|---|---|
| 1 | 파랑 | `#2A78D6` | 5 | 자홍 | `#E87BA4` |
| 2 | 주황 | `#EB6834` | 6 | 초록 | `#008300` |
| 3 | 청록 | `#1BAF7A` | 7 | 보라 | `#4A3AA7` |
| 4 | 노랑 | `#EDA100` | 8 | 빨강 | `#E34948` |

- 인접 슬롯 최저 색약 구분 거리 ΔE 9.1 (기준 8 이상), 일반 시야 ΔE 19.6 (기준 15 이상) — 둘 다 통과.
- **슬롯 순서 자체가 색약 안전장치입니다.** 색을 바꾸려면 순서도 다시 검증해야 합니다.
- 계열이 9개를 넘으면 9번부터는 **의도적으로 회색**으로 칠하고 경고를 띄웁니다. 색을 돌려쓰면 서로 다른
  계열이 같은 색이 되어 차트가 거짓말을 하게 됩니다. 나머지를 "기타"로 묶거나 차트를 나누세요.
- 청록·노랑·자홍은 흰 배경에서 명암비가 3:1 미만입니다. 계열이 3개 이상이면 범례만으로 부족할 수 있으니
  데이터 레이블을 함께 켜는 것을 권합니다.

## 설정 바꾸기

`src/ChartFormatter.bas` 상단 `SETTINGS` 블록의 상수만 고치면 됩니다.

| 상수 | 기본값 | 설명 |
|---|---|---|
| `FONT_LATIN` / `FONT_EASTASIA` | `Malgun Gothic` | 영문·숫자용 / 한글용 폰트 |
| `FONT_SIZE_BASE` / `FONT_SIZE_TITLE` | `10` / `14` | 본문 / 제목 크기 (pt) |
| `APPLY_SIZE` | `True` | `False` 로 두면 **크기도 건드리지 않음** |
| `CHART_WIDTH` / `CHART_HEIGHT` | `480` / `300` | 차트 크기 (pt) |
| `LINE_WEIGHT` | `2` | 꺾은선 두께 (pt) |
| `MARKER_SIZE` | `6` | 마커 크기 (pt) |
| `GAP_WIDTH` | `80` | 막대 간격 너비. 작을수록 막대가 굵어짐 (0~500) |
| `OVERLAP_CLUST` | `-5` | 묶은 막대 계열 사이 틈. 누적 차트는 자동으로 100 고정 |
| `SMOOTH_OFF` | `True` | 꺾은선의 곡선 보정 해제 |
| `LEFT_ALIGN_TITLE` | `True` | 제목 왼쪽 정렬 |
| `PIE_DATA_LABELS` | `True` | 원형 차트에 레이블 표시(대신 범례 숨김) |
| `VALUE_AXIS_FORMAT` | `""` | 값 축 숫자 서식. 예: `"#,##0"`. 빈 값이면 **건드리지 않음** |

색상 상수는 `&HBBGGRR&` 형식(RGB 순서가 거꾸로)입니다. `#2A78D6` → `&HD6782A&`.
주석에 원래 HEX를 같이 적어두었으니 바꿀 때 주석도 함께 고치세요.

## 주의사항

- **`Ctrl` + `Z` 로 되돌릴 수 없습니다.** VBA가 실행되면 엑셀의 실행 취소 기록이 지워집니다.
  처음 써 볼 때는 파일을 복사해두거나 사본에서 시도하세요.
- 시트가 보호되어 있으면 차트 크기 조정이 실패할 수 있습니다. 보호를 먼저 해제하세요.
- 3차원 차트는 일부 서식이 적용되지 않고 경고가 뜹니다. 원근 왜곡 때문에 값을 잘못 읽게 되므로
  평면 차트를 쓰는 게 좋습니다.
- 보조 축(축이 2개)이 있으면 서식은 적용하되 경고를 띄웁니다. 축척이 다른 두 지표는 차트를 2개로
  나누거나 같은 기준으로 지수화하는 편이 오해가 적습니다.
- 코드의 주석과 메시지는 영문입니다. VBA 편집기의 파일 가져오기는 파일을 시스템 코드페이지로 읽기
  때문에, UTF-8 한글 주석을 넣으면 깨져서 들어옵니다. 한글 주석 버전이 필요하면 CP949로 따로
  만들어 드릴 수 있습니다.
