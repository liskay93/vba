# ChartFormatter — 엑셀 차트 서식 자동화 VBA

차트는 직접 만들고, **차트를 클릭해서 선택한 뒤 매크로를 실행**하면 색상·폰트·축·범례 서식이 한 번에 적용됩니다.
**차트 위치(Left/Top)는 절대 바뀌지 않습니다.**

폰트와 색상은 기존 ESG 리포트 매크로(`bar` / `line` / `Doughnut` / `DataLabel_Add`)의 하우스 스타일을 따릅니다.

## 설치

`src/ChartFormatter.bas` 는 한글 폰트 이름이 들어 있어 UTF-8 입니다. 두 가지 방법 중 하나로 넣으세요.

- **복사-붙여넣기 (권장)** — 파일을 열어 전체 복사 → `Alt`+`F11` → 삽입·모듈 → 붙여넣기.
  클립보드는 유니코드로 전달되므로 인코딩 문제가 없습니다.
- **파일 가져오기** — VBA 편집기의 가져오기는 파일을 시스템 코드페이지(CP949)로 읽습니다.
  메모장에서 파일을 열고 **다른 이름으로 저장 → 인코딩: ANSI** 로 저장한 뒤 `Ctrl`+`M` 으로 가져오세요.
  (ANSI 저장이 가능하도록 CP949 로 표현할 수 없는 문자는 쓰지 않았습니다.)

통합 문서는 **매크로 사용 통합 문서(.xlsm)** 로 저장해야 합니다.

## 사용법

| 하려는 일 | 실행할 매크로 |
|---|---|
| 선택한 차트 1개 | `FormatSelectedChart` |
| 현재 시트의 모든 차트 | `FormatAllChartsOnSheet` |

차트를 클릭해서 선택 → `Alt`+`F8` → `FormatSelectedChart` → 실행.

**단축키 등록을 권장합니다.** `Alt`+`F8` → 매크로 선택 → **옵션** → 바로 가기 키에 `Shift`+`F` 입력.
그러면 차트 클릭 후 `Ctrl`+`Shift`+`F` 만 누르면 됩니다.

> 시트에 **버튼 도형을 만들어 연결하는 방식은 쓰지 마세요.** 버튼을 누르는 순간 차트 선택이 풀립니다.
> (`FormatAllChartsOnSheet` 는 선택이 필요 없으므로 버튼으로 써도 됩니다.)

## 폰트 — 기존 코드 그대로

| 대상 | 폰트 | 크기 |
|---|---|---|
| 차트 전체 기본(축·눈금) | 맑은 고딕 | 8.5 pt |
| 범례 | KoPubWorld돋움체 Medium | 9 pt |
| 제목 | 맑은 고딕 굵게 | 12 pt |
| 원형·도넛 레이블 | 맑은 고딕 굵게, 흰색, 가운데 | 8.5 pt |

모든 차트 텍스트는 검정(`RGB(0,0,0)`), 축 선은 검정 0.25pt + 눈금 안쪽 — 기존 코드와 동일합니다.
한글이 깨지지 않도록 `.Name` 뿐 아니라 `.NameFarEast`, `.NameComplexScript` 까지 함께 지정합니다.

# 색상 — 진단과 권장안

## 지금 팔레트의 문제

기존 배열은 다음과 같습니다. 기존 코드가 차트 배경을 지우므로(`ChartArea.Fill.Visible = msoFalse`)
실제 배경은 시트 흰색입니다. 흰 배경 기준으로 측정한 결과입니다.

| # | 색 | 흰 배경 명암비 | 판정 |
|---|---|---|---|
| 1 | `#0039B6` | 9.29 : 1 | 좋음 |
| 2 | `#BDD2FF` | 1.52 : 1 | 너무 연함 |
| 3 | `#DDE9F7` | **1.23 : 1** | 거의 보이지 않음 |
| 4 | `#7F7F7F` | 4.00 : 1 | 좋음 |
| 5 | `#D8D8D8` | 1.43 : 1 | 너무 연함 |
| 6 | `#00C800` | 2.27 : 1 | 탁함 + 미사용(아래 버그) |

구분 가능성은 더 심각합니다. 색 사이 거리(dE, 15 이상이어야 일반 시야에서 구분됨):

- 막대·선 (이웃한 계열끼리): **`#DDE9F7` ↔ `#BDD2FF` = dE 8.0** — 정상 시야에서도 거의 같은 색
- 도넛 (모든 조각이 동시에 보임): **`#D8D8D8` ↔ `#DDE9F7` = dE 5.2** — 사실상 같은 색

원인은 취향이 아니라 **역할 혼동**입니다. 1·2·3번은 파랑 한 색의 진하기 단계(순차),
4·5번은 회색 단계인데, 이걸 하나의 배열에 넣고 "서로 다른 대상"에 순번으로 배정하고 있습니다.
순서가 있는 데이터에는 진하기 단계가 맞지만, 서로 다른 회사·항목을 구분하는 데는 색상(hue)이 달라야 합니다.

## 덧붙여: 6번째 색은 적용되지 않습니다

```vba
colorIndex = colorIndex + 1
If colorIndex > UBound(colorRGB) Then colorIndex = 0   ' UBound = 5 (요소 6개)
ser.Format.Fill.ForeColor.RGB = colorRGB(colorIndex - 1)
```

계열 6에서 `colorIndex` 가 6이 되어 0으로 초기화되고, `colorRGB(-1)` 이 되어 **아래 첨자 사용 오류**가
납니다. `On Error Resume Next` 가 이를 삼키므로 **계열 6은 엑셀 기본색으로 남습니다.**
결과적으로 `#00C800`(초록)은 어떤 계열에도 배정되지 않는 죽은 색이고, 순환은 6이 아니라
7번째 계열에서 일어나 계열 1과 7이 같은 파랑이 됩니다.

## 권장안 — 용도를 두 개로 나눕니다

`PALETTE_MODE` 상수 한 줄로 전환합니다.

### A. `"CATEGORICAL"` — 서로 다른 대상 (당사/경쟁사/업종 등)

| 슬롯 | 색 | HEX | 명암비 |
|---|---|---|---|
| 1 | 브랜드 블루 | `#0B45C4` | 7.89 : 1 |
| 2 | 주황 | `#E8730C` | 3.05 : 1 |
| 3 | 청록 | `#00897B` | 4.32 : 1 |
| 4 | 황토 | `#8A6D00` | 4.92 : 1 |
| 5 | 자주 | `#7B1FA2` | 8.20 : 1 |
| 6 | 적자 | `#C2185B` | 5.87 : 1 |

6색 전부 명암비 3:1 이상이고, 이웃 계열 간 색약 구분 dE 11.8 / 일반 시야 dE 15.5 로
**모든 항목을 통과합니다.**
현재 팔레트는 6색 중 4색이 3:1 미만인데, 권장안은 0색입니다.
  가장 빡빡한 색은 주황 `#E8730C` 의 3.05:1 로 기준을 겨우 넘깁니다. 더 진한 `#D96400`(3.64:1) 도
  검토했지만 **채택하지 않았습니다** — 명암비는 나아지지만 적색맹 시야에서 황토 `#8A6D00` 과
  dE 3.4 로 붙어버려 도넛 조각 상한이 4에서 3으로 줄어듭니다. 슬롯 4를 다른 색으로 바꿔 피해
  보려 했으나, 어두운 주황은 어두운 노랑·초록 계열 전체와 충돌해 해결되지 않았습니다.

- **도넛·원형은 4조각까지만** 안전합니다. 5조각이 되면 자주(`#7B1FA2`)와 브랜드 블루가
  적색맹 시야에서 붙어버립니다. 조각이 5개를 넘으면 매크로가 경고를 띄웁니다.
- **브랜드 블루를 `#0039B6` 에서 `#0B45C4` 로 한 단계 밝혔습니다.** 원래 색은 밝기가 권장
  밴드(L 0.43~0.77)보다 어두운 L 0.412 여서 이 항목만 계속 걸렸습니다. 눈으로는 거의 같은
  파랑이고 명암비도 7.89:1 로 충분합니다. 원래 색으로 되돌리려면 `C_CAT1` 을 `&HB63900&`
  로 바꾸면 됩니다 (주석에 적어두었습니다).

### B. `"SEQUENTIAL"` — 순서가 있는 구간 (누적 막대, 등급, 구간별 비중)

| 단계 | HEX | 명암비 |
|---|---|---|
| 1 (진함) | `#00246B` | 14.34 : 1 |
| 2 | `#0B45C4` | 7.89 : 1 |
| 3 | `#4A7FD9` | 3.94 : 1 |
| 4 (연함) | `#86B6EF` | 2.11 : 1 |

기존 파랑 3단계(`#0039B6` → `#BDD2FF` → `#DDE9F7`)를 대체합니다. 2단계는 범주형 1번과 같은 브랜드 블루입니다. 밝기가 단조 증가하고
단계 간 간격이 충분하며, 가장 연한 끝도 흰 배경에서 보입니다(기존 `#DDE9F7` 은 1.23:1 로 사실상 안 보임).

### 역할색 — 순번으로 배정하지 않는 고정색

| 역할 | HEX | 용도 |
|---|---|---|
| `C_NEUTRAL` | `#7F7F7F` | 기타·비교군. 기존 회색 그대로 유지 (4.00:1) |
| `C_ACCENT` | `#0CA30C` | 강조용 초록. 기존 `#00C800`(2.27:1) 대체 (3.35:1) |

`#D8D8D8` 은 **버렸습니다.** 1.43:1 로 흰 배경에서 보이지 않습니다. 회색 두 단계가 꼭 필요하면
`#595959` + `#A6A6A6` 조합을 쓰세요.

초록은 계열 색이 아니라 **강조 역할**로 고정하는 편이 좋습니다. 순번 6번에 초록을 두면
"6번째 계열"이라는 뜻과 "환경/양호"라는 뜻이 섞여 읽힙니다.

### 색이 슬롯보다 많으면

돌려쓰지 않고 **회색으로 떨어지며 경고를 띄웁니다.** 순환시키면 서로 다른 계열이 같은 색이 되어
차트가 거짓말을 하게 됩니다. 나머지를 '기타'로 묶거나 차트를 나누세요.

## 적용되는 나머지 서식

- **크기** — 기본값은 **건드리지 않음**(`APPLY_SIZE = False`). 리포트 그리드(198/311/510/623 × 215)를
  쓰려면 `True` 로 바꾸고 `CHART_WIDTH`/`CHART_HEIGHT` 를 지정하세요. 위치는 어느 쪽이든 보존됩니다.
- **축** — 검정 0.25pt, 눈금 안쪽, 보조 눈금선 제거. 그리드는 기본 제거(`SHOW_GRIDLINES = False`).
- **범례** — 계열 2개 이상이면 위쪽에 표시, 1개면 제거. 원형·도넛은 레이블이 있으면 범례 생략.
- **막대** — 간격 너비 80, 계열 사이 미세한 틈, 경계는 배경색 1.5pt 선으로 분리. 누적은 `Overlap = 100` 고정.
- **선** — 두께 1.5pt, 곡선 보정 해제, 마커가 있으면 5pt + 흰 테두리(없던 마커는 만들지 않음).
- **원형·도넛** — 조각별 색상 + 흰색 굵은 레이블(항목명 + 값), 가운데 배치.
- **제거** — 그림자, 네온, 차트 테두리, 둥근 모서리, 그림 영역 배경.

혼합 차트(막대+선)는 계열별 종류를 각각 판별해서 알맞게 처리합니다.

## 설정 바꾸기

`src/ChartFormatter.bas` 상단 `설정` 블록의 상수만 고치면 됩니다.

| 상수 | 기본값 | 설명 |
|---|---|---|
| `PALETTE_MODE` | `"CATEGORICAL"` | `"SEQUENTIAL"` 로 바꾸면 파랑 4단계 사용 |
| `FONT_BODY` / `FONT_LEGEND` | 맑은 고딕 / KoPubWorld돋움체 Medium | |
| `FONT_SIZE_BASE` / `FONT_SIZE_LEGEND` / `FONT_SIZE_TITLE` | `8.5` / `9` / `12` | pt |
| `APPLY_SIZE` | `False` | `True` 면 아래 크기 적용 |
| `CHART_WIDTH` / `CHART_HEIGHT` | `311` / `215` | pt |
| `LINE_WEIGHT` / `MARKER_SIZE` | `1.5` / `5` | pt |
| `GAP_WIDTH` | `80` | 작을수록 막대가 굵어짐 (0~500) |
| `AXIS_WEIGHT` | `0.25` | 축 선 두께 |
| `SHOW_GRIDLINES` | `False` | `True` 면 값 축 가로 그리드 표시 |
| `PIE_DATA_LABELS` | `True` | 원형·도넛 레이블 표시(대신 범례 숨김) |
| `VALUE_AXIS_FORMAT` | `""` | 예: `"#,##0"`. 빈 값이면 건드리지 않음 |

색상 상수는 `&HBBGGRR&` 형식(RGB 역순)입니다. `#0B45C4` → `&HC4450B&`.
주석에 원래 HEX 를 같이 적어두었으니 바꿀 때 주석도 함께 고치세요.

## 주의사항

- **`Ctrl`+`Z` 로 되돌릴 수 없습니다.** VBA 실행 시 엑셀의 실행 취소 기록이 지워집니다.
  처음엔 사본에서 시도하세요.
- 시트가 보호되어 있으면 크기 조정이 실패할 수 있습니다.
- 3차원 차트, 보조 축이 있으면 경고를 띄웁니다.
- `KoPubWorld돋움체 Medium` 이 설치되지 않은 PC 에서는 범례가 대체 폰트로 표시됩니다.
